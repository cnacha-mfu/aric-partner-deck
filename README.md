# ARIC — คำเชิญร่วมเป็นพันธมิตร

Partner invitation deck for **ศูนย์นวัตกรรมด้านปัญญาประดิษฐ์และหุ่นยนต์
มหาวิทยาลัยแม่ฟ้าหลวง (MFU-ARIC)** — ๖ สไลด์

**ดูสไลด์:** https://cnacha-mfu.github.io/aric-partner-deck/

## ร่วมเป็นพันธมิตรได้ ๓ ทาง

| | | |
|---|---|---|
| **๑ ให้โจทย์** | ตั้งโจทย์จริงเป็นหัวข้อแฮกกาธอน | ได้ ๓ ทีมแข่งกันแก้ · MVP ที่ทดสอบกับผู้ใช้จริง |
| **๒ ร่วมคัดทีม** | นั่งกรรมการคัดเลือก · ส่งที่ปรึกษาประกบทีม | เห็นทีมก่อนตลาด · ที่นั่งกรรมการบริหารศูนย์ |
| **๓ ร่วมลงทุน** | ลงทุนรอบ pre-seed | หุ้นในบริษัท · ลงทุนเคียงข้างกองทุนมูลนิธิ |

กลไก — แฮกกาธอน → รอบ MVP → ออกบูธ หมุนซ้ำปีละ ๓ รอบ

## หมายเหตุ

เอกสารนี้เป็น **แนวคิดเพื่อการหารือ** — โครงสร้างการถือหุ้นและเงื่อนไขความร่วมมือ
ยังไม่ผ่านการอนุมัติจากสภามหาวิทยาลัยและมูลนิธิ และยังไม่ระบุวงเงิน
